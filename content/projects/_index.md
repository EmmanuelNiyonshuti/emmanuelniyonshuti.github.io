- [anyquart](https://github.com/EmmanuelNiyonshuti/anyquart) — A fork of Quart (Python asgi web framework that runs on asyncio) that runs on AnyIO.

- [anyquart_pydantic](https://github.com/EmmanuelNiyonshuti/anyquart_pydantic) — anyquart extension for request and response validation with pydantic.

- [pymakepublic](https://github.com/EmmanuelNiyonshuti/pymakepublic) - a very small package to explicitly mark your public Python APIs with ``@pub`` rather than creating an ``__all__`` list and adding to or updating it whenever you change your public APIs.

- [sage](https://github.com/EmmanuelNiyonshuti/sage) - an experimental backend pplication that periodically ingests NDVI (Normalized Difference Vegetation Index) data from the Sentinel Hub API for farm boundaries, data is stored in a relational database, aggregated into time series, and used to generate basic alerts such as vegetation decline, sustained low NDVI, or drought_risk.

- [sualw](https://github.com/EmmanuelNiyonshuti/sualw) — A commandline tool for silencing process logs and toggling them on demand.
